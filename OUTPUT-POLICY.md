# Generated Adapter Output Policy (MCP-AQL)

This document describes the **normative policy** for adapters generated by the MCP-AQL toolchain.

For the full policy spec used to drive implementation, see `spec/docs/licensing-options.md` (Section **17**).

## Summary

- The MCP-AQL toolchain is licensed under **AGPL-3.0** (see `LICENSE`).
- **No output exception is granted.**
  - There is no blanket permission to use generated adapters under terms other than the toolchain/runtime copyleft.
- A **commercial license** is available as the off‑ramp for closed-source use (see `COMMERCIAL-LICENSE.md`).
  - Commercial terms include restrictions such as **no reverse engineering** and **no competitive re-implementation** (see `spec/COMMERCIAL-LICENSE-TERMS.md`).

## Required files in generated adapters

By default, every generated adapter MUST include at its root:

- `LICENSE` (AGPL-3.0 text for included/vendored MCP-AQL runtime/template code)
- `NOTICE.md` (attribution; must name Mick Darling; must be preserved)
- `COMMERCIAL-LICENSE.md` (commercial licensing pointer, including self-serve <$1M option)
- `MCPAQL-PROVENANCE.json` (machine-readable provenance; includes schema fingerprint + canary)

## Required runtime/provenance behavior

Generated adapters MUST:

- Depend on (or embed) MCP-AQL runtime/template code licensed under AGPL-3.0 in a non-trivial way (so “use the toolchain or reimplement” is the tradeoff).
- Include provenance fields in `introspect` responses under `result.meta`:
  - `mcpaql_spec_version` (source of truth: `spec/SPEC_VERSION`)
  - `generator_name` (default: `mcpaql-adapter-generator`)
  - `generator_version`
  - `generator_commit`
  - `schema_fingerprint`

## Schema fingerprint definition

The `schema_fingerprint` must be stable across languages/platforms. Use canonical JSON (JCS / RFC 8785) + SHA-256.

## Implementation note (for generator authors)

This repo should implement these requirements in the adapter generator output templates/scaffolding so downstream users cannot “accidentally” omit the required licensing/provenance artifacts.
